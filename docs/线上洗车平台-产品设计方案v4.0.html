4.3 工时联动的五个模块

  1. 工位档期：按 H 占 30 分钟单元，E2 占用、E3 释放；v3.0 的 90 分钟固定告警改为「标准 ×1.2 + 10min」的动态阈值。
  2. 派单产能：洗车工当日累计 T 不超过可用时长（建议 ≤8h），抢单与指派均校验，防止超派导致超时与实收时薪下降。
  3. 多退少补：现场加购增值项、实际里程/等候超预估时，按 order_item 明细补扣，需用户确认并设单笔上限（v2.0 口径）。
  4. 门店评价：「工位占用时长」维度由 E2/E3 时间戳自动生成，以 H 为基准，只有超阈值才扣分（v3.0 防滥用设计的延续）。
  5. 三端收益校验：洗车工 worker_net / T、门店 M / H、平台单均净留存，是第七章调价的核心观测指标。
工时不是承诺、是可校准的基准：行业公开资料显示快洗约 10–30 分钟、标洗约 30–40 分钟、精洗 1–2 小时以上，本表与之量级一致。但门店设备、季节（冬季 / 雨季）、车况差异显著，故所有工时为建议值，试点期按「实际 / 标准」达成率实测校准，校准前不作为对外承诺或考核依据。

7.2 灰度调价与校准触发（图 9）

后台配置 → 1~2 个试点城市灰度（新旧版本按城市路由）→ 观测 7~14 天 → 判定 → 全量或校准 / 回滚。判定条件是「三端底线 + 用户可接受」四条同时成立：洗车工实收时薪 ≥¥45/h、门店工位时产 ≥¥30/h、平台单均净 > 0、用户实付落在公开区间且转化率未显著下滑。
